# 지원서 자동입력 (크롬 확장)

지원서 화면의 인적사항·병역·우대사항·학력·자격증·어학·경력·교육 칸을 내 정보로 채웁니다.

**할 수 있는 일:** 웹 지원서 채우기(국내 그리팅·나인하이어·recruiter·CJ·구글 설문, 해외 Greenhouse·Lever·Ashby) · 증명사진 자동 첨부(사진 칸만) · 회사 양식 파일 채우기(한글 .hwp·.hwpx, Word, PowerPoint, 미리보기 후 내려받기) · 내 이력서 내보내기(Word·PDF, 한국어·영문, 넣을 항목 고르기) · 지원 기록. 자세한 사용법은 `guide/안내서.md`(배포본에는 PDF)에 있습니다.

- 내 정보는 잠금 암호로 전부 암호화(AES-256-GCM, PBKDF2 60만 회)되어 이 크롬 안에만 저장되며 인터넷으로 보내지 않습니다.
- 잠금 암호는 어디에도 저장하지 않습니다. 잊어버리면 복구할 수 없습니다. 크롬을 닫으면 다시 잠깁니다.
- 제출 버튼은 누르지 않습니다. 확인과 제출은 직접 합니다.
- 주민등록번호, 인증번호, 비밀번호, 자기소개서 칸은 건드리지 않습니다.

## 설치 (1회)

1. 이 저장소의 **Releases**에서 최신 zip을 내려받아 압축을 풉니다. (공식 배포본은 Releases뿐입니다. `SECURITY.md` 참고)
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** → 압축을 푼 폴더 선택
5. 주소창 오른쪽 퍼즐 아이콘 → "지원서 자동입력" 옆 핀 눌러 고정

## 사용

1. 확장 아이콘 → **내 정보 설정** → 잠금 암호 정하기(8자 이상) → 정보 입력 → **저장** (처음 1회)
2. 지원 사이트에서 본인인증까지 마치고 지원서 화면을 엽니다
3. 확장 아이콘 → (크롬을 켠 뒤 처음이면 잠금 암호 입력) → **이 페이지 채우기**
4. 초록 테두리 = 채운 칸, 노란 테두리 = 직접 확인할 빈 칸
5. 내용 확인 → 자기소개서 작성 → 직접 제출

## Touch ID · 키체인으로 잠금 해제

1. 한 번만(Mac 전용, 저장소 코드 필요): `chrome://extensions`에서 이 확장의 ID를 복사한 뒤 터미널에서 `EXT_ID=<복사한 ID> ./native/install.sh` 실행. 도우미를 소스(`pubfill-keychain.swift`)에서 만들어 ~/Library/Application Support/pubfill 에 복사하고 크롬에 등록합니다(Xcode 명령줄 도구 필요).
2. 내 정보 설정 → 잠금 암호로 연 뒤 머리글 **🔑 키체인에 저장** → Touch ID 확인
3. 다음부터 팝업·설정 화면에서 **🔑 Touch ID · 키체인으로 잠금 해제**

잠금 열쇠는 macOS 키체인(이 Mac 전용)에 보관되고, 꺼낼 때마다 Touch ID 또는 Mac 암호를 확인합니다.
도우미 소스: `native/pubfill-keychain.swift` (네트워크 없음). 지우기: 설정의 **키체인 사용 중 · 끄기**.

## 자격증 사진으로 불러오기

내 정보 설정 → 자격증 칸 위 **자격증 이미지 올리기** 상자에 이미지를 끌어다 놓거나, 상자를 클릭하고 ⌘ + V로 붙여넣거나, **파일 선택**으로 여러 장 고르기.
사진 한 장에 자격증이 여러 개 있어도 위 → 아래, 왼쪽 → 오른쪽 순서로 나눠 넣습니다. 노란 줄을 확인하고 저장하세요.
자격증번호·날짜는 사진 상태에 따라 틀릴 수 있습니다.

## 회사 양식 파일 · 이력서 내보내기 · 지원 기록

- **회사 양식 채우기:** 내 정보 설정 맨 위에 양식 파일을 끌어놓기 → 미리보기 확인(노란 점선 칸은 눌러서 항목 알려 주기) → **내려받기**로 `_채움` 파일 저장. 원본은 그대로입니다.
- **내 이력서 내보내기:** 내 정보 설정의 **Word(.docx)로 내보내기** 또는 **PDF로 저장** → 넣을 구역·자격증 고르기 → 저장. 언어에서 영문 이력서도 고를 수 있습니다.
- **증명사진:** 내 정보 설정의 증명사진 구역에서 사진 고르기(3:4로 자름). 이력서·Word 양식 사진 칸, 웹 지원서 사진 첨부 칸에 들어갑니다.
- **지원 기록:** 웹 지원서를 채우거나 양식을 내려받거나 이력서를 내보내면 자동으로 한 줄 추가. 상태·메모를 적고 저장합니다(암호화).

## 칸을 잘못 채우거나 못 채울 때

확장 아이콘 → **칸 목록 복사 (값 제외)** → 이 저장소의 **Issues**에 사이트 주소와 함께 붙여 넣기.
칸 이름과 구조만 복사되고 입력값은 포함되지 않습니다. 이 목록으로 인식 규칙(`schema.js`, `fill.js`)을 고칩니다.
같은 칸 이름을 다시 만나면 팝업의 **칸 알려 주기**로 직접 연결해 둘 수도 있습니다.

## 백업

설정 화면의 **암호화 백업 저장**으로 `my_info_backup_encrypted.json`을 받아 둘 수 있습니다. 백업도 암호화되어 있어 잠금 암호 없이는 읽을 수 없습니다. 암호화 이전 버전에서 만든 `my_info_backup.json`이 있다면 지워 주세요.

## 고치거나 기능을 보탤 때

**내 AI 에이전트로 고치기:** 이 저장소를 내려받아 Claude Code·Codex·OpenCode·Cursor 같은 AI 에이전트에게 "이 사이트에서 ○○ 칸이 안 들어간다"고 말하고 팝업의 **칸 목록 복사** 결과를 붙여 넣으면 됩니다. 에이전트는 `AGENTS.md`(원칙, 구조, 고치는 순서)를 읽고 따릅니다. 나만 쓰는 규칙은 `AGENTS.local.md`에 적으면 저장소에 올라가지 않습니다.

- **안 되는 사이트 알리기:** Issues → New issue → **안 되는 사이트 알리기** 양식에 사이트 주소와 칸 목록 복사 결과를 붙여 넣어 주세요. 코드를 몰라도 됩니다.
- **직접 고쳐서 보내기:** 아래 기준을 지켜 수정 제안(Pull Request)을 보내 주세요. 제안 양식의 확인 칸을 채우면 됩니다. 제안이 오면 **원칙 검사**(`test/guard.py`: 외부 전송·권한·암호화·제출·개인정보)가 자동으로 돌아갑니다.

새 사이트 대응이나 버그 수정을 보내 주시면(Pull Request) 아래를 확인한 뒤 받습니다.

1. **개인정보 원칙을 지킵니다.** 외부 서버로 보내는 코드, 제출·로그인·본인인증 버튼을 누르는 코드, 암호화를 약하게 하는 코드는 받지 않습니다. (`SECURITY.md`)
2. **가짜 정보로만 시험합니다.** 실제 이름·연락처·화면 캡처를 올리지 마세요. 시험 페이지는 `test/`에 가짜 지원서로 만듭니다.
3. **전체 자동 시험을 통과해야 합니다.** `test/headless/all.sh` (크롬 필요, 원칙 검사 포함, 사용법은 `test/headless/README.md`)
4. 버전을 올릴 때는 `manifest.json`의 version과 `fill.js`의 `ENGINE`을 함께 올립니다.
